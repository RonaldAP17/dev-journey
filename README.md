# dev-journey

Deliberate practice, 30 minutes a day. Rebuilding my fundamentals from the ground up, learning in public.

## The rules
- 30 minutes every day, minimum.
- I write the code first, on my own — no AI. Only after I've worked through it do I bring it to review.
- One small commit a day. The streak is the point.
- If I already know something cold, I skip it and level up. Skipping is not quitting.

## Roadmap
- **01-php-wp** — PHP fundamentals → WordPress / Kirby templating (hooks, custom post types, ACF).
- **02-js-react** — JavaScript fundamentals → React. (Later — weak JS is building on sand.)

Started August 2026.
